数据与防剧透机制说明

数据来源：本页数据由「逐章阅读 Agent」产出——处理第 N 章时，Agent 只能看到第 1~N 章原文与之前章节的人物状态，每条结论都须附原文引句（内置《刀锋》示例为手工演示数据）。

防剧透规则：读到第几章，就只看到第几章为止的「已知信息」——人物、称呼、关系、身份，全部按章节戳过滤，不存在预载全书。关系结束后不删除，保留为虚线的「已知历史」。

  1. 导入书籍原文（txt）→ 自动切章，人工预览确认切分点；
  2. Agent 逐章阅读，每章产出带章节戳的增量补丁：新人物 / 新称呼 / 新关系 / 关系结束 / 身份更新，append-only 永不覆盖；
  3. 前端所有查询严格按「起始章 ≤ 当前阅读章」过滤；未读章节连标题都不显示。

书籍原文与抽取结果都存在本机 daodu-local/books/ 目录，不上传任何服务器（调用大模型 API 时章节文本仅发送给模型服务商）。
